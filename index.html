About Pdf Editor Craft

Pdf Editor Craft is a free online PDF editor and toolkit for students, teachers, freelancers, and office workers. It edits text in PDF files, merges, splits, rotates, and numbers pages, adds watermarks, and converts JPG and PNG images to PDF. Everything runs in your browser with the open-source libraries pdf-lib and PDF.js, so your documents are never uploaded to a server.

FAQ

Are my files uploaded anywhere?

No. Every tool runs inside your browser. Closing the page clears everything.

Can I edit text in any PDF?

You can edit text in PDFs that contain real text. Scanned PDFs (photos of pages) need OCR, which is coming later. Replacement text uses the Helvetica font and English letters.

Is there a file size limit?

Each file can be up to 50 MB. Large files may be slow on older phones.

Is Pdf Editor Craft free?

Yes. All tools are free, with no sign-up and no watermark added to your files.

Which PDF tools are available?

Edit PDF text, merge PDF, extract pages, remove pages, rotate PDF, image to PDF, page numbers, and watermark.
